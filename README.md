## 📌 Proyectos Destacados

### 🚗 Smart Parking System
Sistema de estacionamiento inteligente desarrollado con Flutter, Firebase e IoT.
- ✨ Reservas inteligentes y gestión de espacios en tiempo real.
- 🔐 Autenticación mediante Firebase Authentication y Realtime Database.
- 🤖 Integración con sensores ultrasónicos para control físico de ocupación.

---

### 💧 Sistema de Gestión de Agua Potable
Plataforma administrativa estructurada para la gestión de usuarios y servicios de agua potable.
- 📋 Control de cobros, administración de usuarios y registro mediante folios.
- 🗄️ Base de datos relacional optimizada para consultas eficientes.

---

### 🦯 Bastón Inteligente
Proyecto enfocado en la asistencia e inclusión para personas con discapacidad visual.

- 📱 Aplicación móvil complementaria para gestión de alertas de emergencia.
